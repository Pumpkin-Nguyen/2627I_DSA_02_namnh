- Test case mà code chạy sai:
	+ Số phần tử: n = 3
	+ union(0, 1)
	+ union(0, 2)
	+ Kiểm tra phần tử: i = 0 và j = 1
- Các bước chạy:
	+ Khởi tạo dãy leader = [0, 1, 2]
	+ union(0, 1)
		Với i = 0: leader[0] == leader[0] -> leader[0] = leader[1] = 1
		Với i = 1: leader[1] == leader[0] -> leader[1] = leader[1] = 1
		Với i = 2: leader[2] != leader[0]
		=> leader = [1, 1, 2]

	+ union(0, 2)
		Với i = 0: leader[0] == leader[0] -> leader[0] = leader[2] = 2
		Với i = 1: leader[1] != leader[0] (1 != 2)
		Với i = 2: leader[2] == leader[0] -> leader [2] = leader[2] = 2
		=> leader = [2, 1, 2]
	+ leader[i] != leader[j] (2 != 1)
- Nguyên nhân: Trong vòng lặp, khi duyệt tới i = p, leader[p] bị ghi thành leader[q]. Tuy nhiên, ở các vòng lặp tiếp theo, đoạn code lại dùng giá trị mới của leader[p] để so sánh nên bị sai.
